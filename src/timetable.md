# 仮スケジュール

::: warning 仮のスケジュールです
時刻や企画は変わることがあります。講義の科目と講師はこれから決まります。
:::

期間は 2027年2月28日（日）〜3月4日（木）、会場は[沖縄県青年会館](https://maps.app.goo.gl/WWgnRZxDTBfwh7Mc8)です。昼休憩は 2月28日〜3月3日の 12:00–13:20 です。講義のあいだには適宜休憩を入れます。

CompPhysHack は英語です。共通講義と個別講義は日本語です。開会、グループセミナー、企業の企画、ポスター、懇親会、フリーディスカッション、総会・閉会式も日本語です。英語で行う講義があれば、その講義だけ予定に書きます。

3月1日〜3月3日の日中は、個別講義（日本語）と CompPhysHack（英語）を並行して行います。初日（2月28日）に CompPhysHack はありません。
