# Hackathon（CompPhysHack2027）

[CompPhysHack2026](https://qc-hybrid.github.io/CompPhysHack2026/) の後継の CompPhysHack2027 を、春の学校の中で開きます。

ハッカソン（Hackathon）は、参加者がチームに分かれて短期間で集中的にプログラムやツールの開発・課題解決に取り組み、最終日に成果を発表する実践型のイベントです。CompPhysHack2027 では「Agentic coding for computational physics」をテーマに、AI を活用した計算物理のコーディング・開発に3日間取り組みます。最初に導入講義とハンズオンがあるため、ハッカソン未経験でも参加できます。計算機を使った研究やプログラミングの経験があれば十分です。実験家の方の参加も歓迎します。

::: warning 仮の内容です
このページのプログラムや講師は仮のもので、予告なく変わることがあります。決まりしだい、このページを更新します。
:::

## 参加のしかた

- 参加登録のときに、Hackathon に参加するかを選びます。登録していない人は参加できません。
- 人数に上限があり、先着順です。
- 3日間 Hackathon に集中できる人に申し込んでほしいです。聞きたい講義があれば、抜けて出てもかまいません。勧めはしませんが、自己責任で OK です。
- 参加しない人は、同じ時間に[講義](/lectures)に出ます。
- 2月28日に出る場合、日本語が分からない人は英語のグループセミナーとポスターを勧めます。開会と AI の研究利用のセッションは、話は日本語でスライドは英語です。
